# Mi Bolivia — portal del juego

Portal web oficial del videojuego **Mi Bolivia** (endless runner 3D hecho en Unity), con la build WebGL jugable en el navegador.

- `index.html`, `css/`, `js/`, `img/`: landing page (Historia, Personaje, Mecánicas, Datos, Jugar ahora).
- `juego/`: build de Unity WebGL (sin compresión, para que funcione en GitHub Pages).
